# Catopia asset manager

## Acquisition rules

- Prefer free, clearly licensed assets from the approved candidate libraries.
- Check the exact asset page, creator, license, attribution and download restrictions before acquisition. Never bypass paywalls, logins, or access controls.
- Do not treat a source homepage or preview as proof that a particular file was acquired or is usable.
- Do not purchase assets or use account credentials without explicit authorization.

## Inspection and registration

For every acquired item, record source URL, creator, license, attribution, local path, format, size, dimensions or model statistics, optimization and intended usage in the asset docs. Inspect files for missing dependencies, duplicates, visual fit and technical compatibility.

For 3D assets, verify GLB/GLTF content, orientation, scale, materials and texture references. For cats, verify a quadruped rig and each animation on the exact model. Keep licensed originals separate from optimized production copies.

## Integration gate

Only add assets to production components after license and compatibility checks pass. Update the catalog, license register and compatibility report together. If network, source terms, or local tooling blocks a step, record the exact blocker and do not claim success.
