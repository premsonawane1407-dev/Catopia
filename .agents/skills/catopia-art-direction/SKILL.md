# Catopia art direction

## Identity

Catopia should feel like a warm indie-game neighborhood built around real campus cats. Use warm cream, sage, forest green, terracotta and butter yellow; layered organic shapes; readable body text; a friendly display face; small hand-drawn details; and restrained motion. Avoid generic SaaS dashboards, repetitive grids, excessive gradients, and decoration that competes with cat photos or map content.

## Workflow

1. Inspect the existing design tokens and nearby pages before adding a new visual pattern.
2. Reuse shared tokens and components. Keep desktop, narrow mobile, keyboard focus, contrast, and reduced-motion behavior in scope.
3. Keep data states honest: distinguish real community data, demonstration fixtures, loading, empty and error states.
4. Use assets only after the asset catalog and license register contain the exact source and rights.
5. Inspect the rendered page at desktop and mobile sizes before calling the change finished.

## Motion

Prefer short, quiet transitions that explain state changes. Respect `prefers-reduced-motion`; never make essential information depend on animation or audio.
