5. Master command for Codex
Copy this entire instruction after the commands and asset list.
CATOPIA — COMPLETE DEVELOPMENT SETUP AND ASSET ACQUISITION
Read all existing Catopia documentation and instructions before executing this task.

I want you to take responsibility for setting up the development environment and acquiring the assets needed to build the complete Catopia experience.
TASK 1 — DEVELOPMENT ENVIRONMENT
Inspect the existing project.

Check Node.js, npm, Git, existing dependencies, and installed Codex skills.

Install missing dependencies for:
- Next.js and React
- TypeScript
- Three.js
- React Three Fiber
- Drei
- GSAP
- Zustand
- MapLibre
- Supabase
- Zod
- React Hook Form
- Lucide React
- Vitest
- Playwright
Do not unnecessarily replace existing dependencies or introduce incompatible versions.
TASK 2 — AGENT SKILLS
Inspect and install suitable skills for:
- Frontend design
- Three.js
- React Three Fiber
- Supabase
- PostgreSQL
- Playwright testing
Use the skills CLI and verify the installations.
TASK 3 — DOWNLOAD AND ORGANIZE ASSETS
Investigate and acquire assets from:
- Kenney
- Quaternius
- Poly Haven
- Poly Pizza
- Sketchfab
- ambientCG
- itch.io
- Figma Community
- Google Fonts
- Lucide
- Freesound
- Pixabay
Prioritize these assets:
1. Six cat variations.
2. Cat-specific quadrupedal animation sets.
3. Campus buildings.
4. Library and cafeteria.
5. Trees, gardens and vegetation.
6. Benches, roads, pathways and streetlights.
7. Environment materials and HDRIs.
8. UI illustrations, logos, badges and icons.
9. Cat and environmental sound effects.
TASK 4 — QUALITY CONTROL
For each downloaded asset:
- Verify the source.
- Verify its license.
- Check the file format.
- Check the model's compatibility.
- Check animation compatibility.
- Check model scale and orientation.
- Optimize file size and textures.
- Remove unnecessary duplicate assets.
- Record the original source and author.
Prefer GLB/GLTF models and web-optimized textures.

Do not bypass paywalls, authentication, or licensing restrictions.
TASK 5 — INTEGRATION
Integrate suitable assets into actual Catopia components.

Build reusable components for cats, buildings, trees, environment props, landmarks and interactive cat previews.

Ensure cat animations are appropriate for quadrupedal models.

Do not merely download assets and leave them unused.
TASK 6 — DOCUMENTATION
Create:
- docs/ASSET_CATALOG.md
- docs/ASSET_LICENSES.md
- docs/ASSET_COMPATIBILITY_REPORT.md
Document downloaded assets, unavailable assets, license information, compatibility and integration status.
TASK 7 — EXECUTION
Continue with the existing Catopia implementation roadmap.

Do not stop at asset acquisition.

Implement the actual product in sequential stages, run tests, inspect the browser output and fix errors.

If network access is disabled, explain exactly how to enable the minimum necessary access. Do not claim downloads or integrations succeeded when they did not.

At the end, provide a report of completed work, downloaded assets, installed dependencies, installed skills, test results, and remaining tasks.
