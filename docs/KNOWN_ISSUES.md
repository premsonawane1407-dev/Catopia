## Verified observations

- No code, assets, configuration, dependency lockfile, tests, or existing documentation directory was found before this work.
- No bug in an existing application was observable because there was no application to run.
- No tests or external asset downloads have been claimed at this point.
- Resolved in game Phase 1 (2026-11-25): the Full tier of look B cost about 20 ms per frame at 1600x900 on an integrated GPU, of which about 13 ms was unexplained. Merging the street into 7 static meshes, 2 prop meshes, 5 window meshes and 1 halo mesh cut draw calls from about 510 to 56 and the Full tier to about 7 ms (Light about 4.5 ms, Minimal about 1.5 ms) on the same PC, viewport and pixel density, in both the dev server and a production build (`docs/phase1/bench-frame-cost-2026-11-25.json`). Per-draw overhead was the cause. Pixel-for-pixel parity with the Phase 0 look was judged by eye against the lab at the same window size (`docs/phase1/captures/`), not by an image diff, except that the bunting flags keep the look test's pastel vertex colours on purpose.
