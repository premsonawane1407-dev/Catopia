HOW THE INSTALL COMMANDS WERE DERIVED
-------------------------------------
Each command uses the "skills" CLI format:

    npx skills add <github-owner/repo> --skill <skill-name>

The repo for each skill comes from skills-lock.json. The commands were NOT
re-run when this file was written, so they are not verified to work today. The
lock file pins an exact commit for every skill. A plain command installs the
repo's latest version, which may differ from the pinned one. The pinned commit
is listed under each group.

The 3 Catopia custom skills are not installed from anywhere. They are written
in this repository and ship with the project.
