# Catopia asset catalog

## Acquisition status

Source packs and a first small set of web assets are now acquired. Candidate files are separated from production assets. The 3D models have passed container/header and metadata inspection, but have not yet been loaded in a Three.js browser viewer because project dependencies are not installed.

| Asset group | Required items | Acquired | Candidate source / notes |
|---|---|---:|---|
| Cats | Orange, white, black, grey, calico, brown tabby | 1 source candidate / 6 | One Quaternius cat GLB acquired; no verified coat variants |
| Cat animations | Walk, run, sit, idle, sleep, groom, stretch, look, tail, jump, turn | 2 potentially relevant clips / 11 | The Quaternius GLB includes `Idle`, `Walk`, and `Jump` among nine clips; clip behavior and quadruped motion remain unverified |
| Campus environment | Buildings, library, cafeteria, paths, garden, trees, benches, lights, gate, signs, props | 18 selected GLBs staged in `public/models/environment/` | Kenney Nature, City Kit Roads, and Furniture source packs acquired; Building Kit retained as modular greybox source |
| Materials | Grass, soil, pavement, brick, wood, roof, stone, water, sky/lighting | 3 source textures acquired | Poly Haven 1K diffuse files were visually inspected; photorealistic appearance does not match the current stylized target, so they are excluded from `public/` pending an art-direction decision |
| Website | Logo, favicon, profile/empty states, map markers, badges, icons, loading art | 2 font families acquired | Nunito and Fraunces Latin variable WOFF2 files plus OFL texts are stored and served locally; remaining bespoke assets are not acquired |
| Audio | Meow, purr, footsteps, birds, wind, leaves, ambience, UI and reward sounds | 1 music file | One recording is the game's background music (listed below); its licence is unverified. The menu sounds are generated by code. No other sound files; each must have per-file license and attribution recorded |

## Candidate packs reviewed

- [Kenney Nature Kit](https://kenney.nl/assets/nature-kit): acquired; includes GLB files and an included CC0 license. Pack preview was inspected. Individual selected models still require a browser render check.
- [Kenney Building Kit](https://kenney.nl/assets/building-kit): acquired; modular pieces only, so it does not provide a ready campus, library, or cafeteria.
- [Kenney City Kit (Roads)](https://kenney.nl/assets/city-kit-roads) and [Furniture Kit](https://kenney.nl/assets/furniture-kit): acquired; previews inspected and selected road/bench parts staged for later integration.
- [Kenney Cube Pets](https://kenney.nl/assets/cube-pets): acquired and inspected. Its cat is a tiny cube-style figure and does not satisfy the current character direction on its own.
- [Quaternius Cat by Quaternius on Poly Pizza](https://poly.pizza/m/2f54vbV0In): acquired from the page's linked GLB; the page identifies the model as Public Domain (CC0). Mesh/rig metadata was inspected but not rendered.
- [Poly Haven](https://polyhaven.com/license): candidate source for HDRIs, textures, and models; prefer compact texture resolutions and verify the selected file metadata before use.
- [ambientCG](https://docs.ambientcg.com/license/): candidate source for materials; prefer web-sized texture sets.
- React Bits UI components (user-supplied source snapshots in `references/`): `GlareHover.tsx/.css`, `FadeContent.tsx` (needs `gsap`, already a dependency) and `DotGrid.jsx/.css` (self-contained WebGL2, typed by `DotGrid.d.ts`) are copied unchanged into `app/community-preview/react-bits/`, apart from an eslint-disable header. They drive the Store category rows only. The remaining ~200 components and background effects in `references/` are not integrated.
- Store subcategory tiles reuse CSS crops of `public/images/paw/toolkit-01.jpg` and `toolkit-04.jpg` (no new files). Crops are defined in `SUBCATEGORY_IMAGES` in `app/community-preview/store-data.ts`; subcategories without a matching object keep the icon tile.
- Store hero images (WebP, from the three user-supplied sources listed in the license register): `public/images/store/hero-everyday.webp` (1600×1067, 49 KB), `hero-play.webp` (640×640, 60 KB), `hero-comfort.webp` (736×1308, 51 KB). Used by `app/community-preview/store-hero.tsx` with per-slide focal points. None matches the brief exactly: slide 1 is a ginger cat outdoors (not on a sofa) and slide 3 is a cream cat sitting on bedding (not sleeping in a cat bed).
- Store product gallery (user-supplied toolkit photos `references/paw/cat tool kit 1–6.jpg` → `public/images/store/gallery/`): 43 square-free 4:5 crops, each in three sizes (`<id>.webp` up to 840px, `<id>-card.webp` 420px, `<id>-thumb.webp` 120px), 3.2 MB in total. Crop coordinates and alt text live in `app/community-preview/store-gallery.json`; `scripts/build-store-gallery.mjs` regenerates the files (needs `sharp`). `app/community-preview/store-gallery.ts` maps 26 products to 1–4 crops each. Only objects that genuinely appear in a photo are mapped; the other 17 products fall back to the concept plate. Real photography can be supplied per product through the optional `Product.images` field.
- React Bits Counter (rolling price digits) and Magnet (magnetic add-to-bag button) are copied unchanged into `app/community-preview/react-bits/` with an eslint-disable header, like the other vendored components.
- Map interface (React Bits, vendored unchanged with an eslint-disable header where needed): `ClickSpark.tsx` (save burst), `StarBorder.tsx/.css` (3D toggle), `GradualBlur.tsx/.css` (place panel scroll edges), `ShinyText.tsx/.css` (loading text), plus the already-vendored Counter, Magnet and GlareHover. No new image files were added for the map.

- Game (Phase 1, 2026-11-25): beyond the files above the game uses no image files and one audio file (the background music, listed above). Brick, stone, plaster, timber, roof-tile and cobble textures, the lit window panes (three atlases of six designs), the window halo and light-pool textures, the shop sign, the wall notices and the light halos are drawn by code when the game starts (`features/game/render/pixel-textures.ts`, `soft-textures.ts`). Crates, barrels, produce, flower pots, bunting and the sign's chains are geometry built by code (`features/game/world/props-geometry.ts`). The pause menu's sounds are generated with the Web Audio API (`features/game/audio/ui-sounds.ts`); the background music is the one recorded sound.

## File register

For every later addition, record exact file path, source page, creator, license, source download date, original file size, optimized size, format, dimensions/poly count/texture resolution where applicable, and component usage. The Kenney ZIP archives retain the original pack files and included `License.txt` files; extracted files are enumerated in the compatibility report and retain copies of each pack license in `assets/3d/` or `assets/source-packs/`.
